スマホで要約する

キーはこの端末の中だけに保存され、Gemini 以外へは送られません。 スマホには字幕を取る仕組み（PC版のローカルヘルパー）が無いため、 動画そのものを Gemini に読ませます。 そのぶん PC 版よりトークンを多く使い、長い動画ほど時間と費用がかかります。

YouTube アプリの「共有」から DARUMA を選ぶと、その動画の要約が始まります。 共有先に出てこないときは、このアプリをホーム画面にインストールしてください。

Google 連携

Google Cloud コンソールで作成した「ウェブ アプリケーション」のクライアント ID です。 承認済みの JavaScript 生成元に、このページの URL を登録しておいてください。

データ

拡張機能が Drive に書き出した daruma-archive.json を読み込みます。 一度取り込めば、オフラインでも閲覧できます。 この端末で作った要約は daruma-mobile.json として書き戻され、 PC 側でアーカイブを開くか「同期」を押したときに取り込まれます。

アプリ

アプリ本体はオフラインでも動くよう端末に保存されています。 更新しても画面が変わらないときは、下のボタンで入れ替えてください。
